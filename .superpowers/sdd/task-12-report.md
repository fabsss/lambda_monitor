# Task 12 Report: Frontend — Gauge, Stats Bars, Settings, Calibration Wizard

## Status: DONE

## Summary
Implemented the vanilla HTML/CSS/JS frontend for Lambda Monitor with three tabs
(Live, Chart, Settings), embedded into firmware at build time via a PlatformIO
pre-build script.

## Files created
- `web/index.html` — tab UI: gauge SVG, status text, switch frequency, session/long-term
  stacked bars, reset button, chart placeholder, settings form + calibration wizard.
- `web/style.css` — minimal styling, zone-colored stacked bars (warmup/lean/lambda1/rich).
- `web/app.js` — tab switching, gauge needle rotation, WebSocket live updates,
  periodic `/api/stats` polling, reset button, config form submit, calibration
  wizard buttons (set λ=1 / u_min / u_max from live voltage).
- `tools/embed_frontend.py` — PlatformIO `Import("env")` pre-build script that reads
  `web/index.html`, `web/style.css`, `web/app.js`, C-escapes their contents, and
  writes `src/frontend_assets.h` with `INDEX_HTML`, `STYLE_CSS`, `APP_JS` string
  constants.

## Files modified
- `platformio.ini` — added `extra_scripts = pre:tools/embed_frontend.py` under
  `[env:esp32s3]`.
- `src/web_server.c` — added `style_get_handler` (serves `text/css`) and
  `app_js_get_handler` (serves `application/javascript`), plus routes
  `/style.css` and `/app.js` registered in `web_server_start()`.

## Files deleted (regenerated)
- `src/frontend_assets.h` — old stub deleted; regenerated automatically by
  `tools/embed_frontend.py` on `pio run -e esp32s3` (now 159 lines, containing
  the real embedded frontend instead of the placeholder page).
